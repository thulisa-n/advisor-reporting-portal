# Skill: Feature Builder

When implementing a feature:
1. understand the business goal first
2. identify required inputs and outputs
3. define reusable components
4. separate UI from calculations
5. keep state management simple
6. create clean utility functions
7. generate validation rules
8. include loading/error states if needed

Always:
- optimize for maintainability
- avoid overengineering
- create demo-friendly UX
