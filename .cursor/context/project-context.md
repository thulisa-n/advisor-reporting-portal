# Project Context

This project is a technical assessment for an AI Automation Engineer role.

Goal:
Demonstrate:
- rapid MVP delivery
- product thinking
- engineering judgment
- AI-assisted development
- clean architecture
- practical tradeoffs

The project is:
A financial advisor portal that:
- stores client profiles
- accepts quarterly balances
- performs automatic financial calculations
- generates polished PDF reports

Key user pain points:
- manual calculations
- time-consuming report preparation
- formatting inconsistencies
- repeated data entry
- operational inefficiency

The users are:
- a small financial planning firm
- non-technical staff
- high-net-worth client advisors

Important constraints:
- no real integrations required
- no authentication needed
- demo-focused implementation
- fixed 2-hour scope expectation

The implementation should feel:
- professional
- trustworthy
- operationally efficient
- maintainable
