# 2-Minute Loom Walkthrough Script

## 0:00-0:20 - Problem Understanding
"We built this portal to solve a very clear operational bottleneck.  
The team was using a manual workflow across spreadsheets and documents, redoing repetitive calculations every quarter, and spending too much time formatting reports.  
PDF generation was a bottleneck, and the full process introduced avoidable errors and operational inefficiency."

## 0:20-0:50 - Show App Structure
"The solution is organized around the real workflow.  
First, we manage client profiles so static information is entered once.  
Second, we capture quarterly balances in a structured form.  
Third, calculations are automatic and update in real time.  
Finally, users can preview outputs and generate SACS and TCC PDFs directly from the app."

## 0:50-1:20 - Engineering Decisions
"From an engineering perspective, I optimized for rapid MVP delivery with clean, maintainable structure.  
The architecture is modular, with calculation and validation logic separated from UI for clarity and reuse.  
I focused on reusable components and deterministic utility functions.  
The workflow is intentionally human-reviewed, and scope was intentionally constrained to fit the 2-hour assessment expectation while still delivering a polished, demo-ready product."

## 1:20-1:50 - Future Enhancements
"For next steps, there are several high-value enhancements.  
We can add Canva export and Dropbox sync for downstream operational workflows.  
We can introduce automated data ingestion and deeper financial integrations in later phases.  
And we can add stronger audit history and report tracking for compliance and traceability."

## 1:50-2:00 - Closing
"Overall, this build focuses on reducing operational overhead, maintaining calculation accuracy, and improving the report generation workflow so the team can prepare client-ready outputs much faster and with higher confidence."
